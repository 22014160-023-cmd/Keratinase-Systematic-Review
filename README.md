# Bacterial Keratinases - Systematic Review

Systematic review of bacterial keratinases for pharmaceutical and cosmetic applications as eco-friendly alternatives to synthetic chemicals.

## Dataset
- **Proteins**: 468 NCBI records
- **PubMed papers**: 237 records
- **Nucleotide records**: 261 records
- **Year range**: 1995-2025
- **Top genera**: Bacillus, Ectobacillus
